# DepotSerif-subset.ttf

Digits-only subset (U+0030-0039) of Liberation Serif Regular 2.1.5, generated
with fontTools subsetter. Used as the fallback-serif face for the depot count
badge: the frozen Playwright baseline renders `.count` text in the browser
default serif (the legacy page's `.count` font rules did not apply at capture
time), so the renderer must reproduce serif digit ink rather than NotoSansHans.

Source: https://github.com/liberationfonts/liberation-fonts/releases (2.1.5)

RFN: no "Liberation" in the file or family name.
